# Actividad 2 - llave de clases y uso

Esta carpeta agrupa la documentación y salidas de apoyo asociadas a la
homologación de clases para la Actividad 2.

## Subcarpetas

- `plot_interactivo_clases_homologadas/`: explorador previo de cobertura,
  presencia/ausencia y clases faltantes por país.
- `analisis_visual_homologacion_a1_a2/`: paquete reproducible de visualizaciones
  ejecutivas sobre resultados A1/A2 y la base homologada.

## Insumos

- `Propuesta_clasificacion_llave_v*.xlsx`: versiones de la propuesta de
  clasificación.
- `clases_consultoria_1_base_a_homologar.xlsx`: insumo base de clases a
  homologar.
